# gm-polyfill

Typed wrappers and fallbacks for common userscript APIs.

## Install

```sh
npm install github:arylo-scripts/gm-polyfill
```

## Usage

```ts
import { GM_addStyle, GM_getValue, GM_setValue } from '@arylo-scripts/gm-polyfill'
```

## Development

```sh
npm install
npm run lint
npm run build
```
